### WIN SCRIPTS

- Simple scripts para configurar diferentes aspectos del sistema operativo Windows.
- Basados en directivas de grupo, documentación e investigaciones de otras personas.
- Enfocado al gaming.
- Uso en Windows 10 y 11.

## reg_kbm_cfg
- Enfocado a reducir el tiempo de respuesta en mouse y teclado, además tiene la posibilidad de quitar todos los sonidos del sistema operativo.

## reg_system_cfg
- Enfocado a evitar/limitar todas las conexiones con Microsoft (telemetria) y funciones innecesarias que puedan afectar a las sesiones de juego.

> [!IMPORTANT]
> Es importante tener el hardware adecuado y con buenas temperaturas para aprovechar el máximo rendimiento de un sistema.

> [!NOTE]
> Usar los scripts en un sistema limpio/actualizado y libre de modificaciones, si va aplicar ajustes avanzados crear un punto de restauración.
> Es posible que su software Antivirus bloquee algunas de las funciones debido a las modificaciones que realiza, como limitar la Seguridad de Windows que afecta al rendimiento.
> Asegúrese de que no esté bloqueado/eliminado y si esto ocurre, añada el script a la lista de programas permitidos.
> Si algun script parece atascado puede presionar alguna tecla random sobre la ventana CMD o "Ctrl + C" para abortar la ejecucion.
> Reiniciar después de cada cambio.
> Se agradecen los comentarios y las críticas constructivas.

> [!TIP]
> Para el script "reg_system_cfg" es conveniente ejecutarlo en Modo Seguro.
